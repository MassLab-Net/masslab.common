# masslab.common

## NuGet release workflow

The GitHub Actions workflow at `.github/workflows/nuget-packages.yml` builds NuGet packages whenever changes are pushed or merged into `master` or `main`.

Versioning is generated by the workflow:

```text
<version_prefix>.<github_run_number>
```

By default this produces versions such as `1.0.123`. The `version_prefix` can be changed when running the workflow manually.

The workflow:

1. Restores `MassLab.Common.sln`.
2. Builds all projects in `Release`.
3. Runs all tests.
4. Packs all non-test projects into `artifacts/packages`.
5. Uploads `.nupkg` files as workflow artifacts.
6. Pushes packages to NuGet when the repository secret `NUGET_API_KEY` is configured.
